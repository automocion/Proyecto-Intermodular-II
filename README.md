# Proyecto Intermodular II · Automoción 2026/27

Web estática preparada para GitHub Pages. No usa compilador, paquetes ni dependencias.

## Publicación rápida
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta a la raíz.
3. Abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la URL pública cuando finalice el despliegue.

## Edición
- `index.html`: estructura y programación general.
- `data.js`: unidades, fechas, tareas, RA, CE e instrumentos.
- `styles.css`: diseño visual y adaptación móvil.
- `app.js`: buscador y creación de tarjetas.
- `PROMPT_GITHUB_COPILOT.md`: instrucciones para ampliar el sitio.

## Recomendaciones antes de publicar
- Añadir nombre y logotipo del centro si se dispone de autorización.
- Revisar la vigencia de la normativa.
- Sustituir o eliminar enlaces internos de Aules que requieran autenticación.
- No publicar nombres, calificaciones ni datos personales del alumnado.
